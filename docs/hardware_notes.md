# Split65 ハード仕様ノート(実機調査の記録)

この文書は v1〜v34 の開発過程で実機とコードから確定した、公式資料に書かれていない仕様のまとめ。

## スイッチ類

| 名称 | 位置 | 役割 | 挙動(実機確定) |
|---|---|---|---|
| 右Shift下スライドスイッチ | 右Shiftキートップ下(裏面) | **右Type-CのUSBデータ線(D+/D-)のON/OFF** | ON=右のUSB列挙・DFU・マスター動作が可能 / OFF=PCがリセット要求に失敗し「コード43」表示 |
| 裏面3位置スライドスイッチ | 左半身裏面 | 接続モード(中央=有線/左=2.4G/右=BT) | `HS_BT_DEF_PIN=C14`/`HS_2G4_DEF_PIN=C15` を50ms毎に読む |
| ピンホール | 左=L-SPキー下 / 右=R-SPキー下 | リセット(モーメンタリ) | 電源投入の瞬間にサンプル → DFU(ROMブートローダー) |

## ポート構成

- 左: Type-C 1個(PC用)+ bridgeコネクタ(右半身への給電と通信)
- 右: **Type-C 1個のみ(bridgeと共用)**。右直挿し中はbridgeが物理的に繋がらない → 左右通信不可・右は単独キーボードとして動作
- 無線モジュールは**左半身のみ**。無線時も bridge 必須(右のキーはbridge→左→BT/2.4G。右は常にスレーブ+bridge給電)

## DFU(ファーム書き込み)

- ブートローダー: WB32 DFU(`bootloader: wb32-dfu`)
- **ソフトDFU(推奨・ピンホール不要)**: 左=Fn+M / 右=右Type-C直挿し+右Shift下スイッチON→Fn+M(FL+M は右半身キーなので右単機で押せる)
- 従来手順(ピンホール短絡→スイッチON→USB直挿し)も有効。ただし「スイッチON→短絡→USB直挿し」の順では入らない(電源投入の瞬間のサンプル仕様)

## 役割判定(v34)

- 既定(QMK split_common): 「自分のUSBが活性な方=マスター」→ 無線モードでは両半身スレーブになり破綻
- v34: マスター=USB活性側、USB無し時は左(モジュール保有側)。右はUSB無し時 `usb_disconnect()` でスレーブ化
- USBライフサイクル: 左(モジュール側)は無線モードで自分のUSBを完全停止(省電力)/右は一切 stop/restart しない(右直挿しマスター運用とソフトDFUのため)

## IME関連(MS-IME実機観測)

- usage `0x8B`(無変換)/`0x8A`(変換)の意味は「各PCのIMEキー割当」と「IMEの状態(未入力/変換中)」の**2重依存**
- 推奨設定: 各PCで「無変換キー=IME-オフ」を割当 → Capsタップ(0x8B送出)で常にIMEオフ(冪等)
- 変換候補表示中のCaps(0x8B)= カタカナ変換になる(IMEオフは発火しない)= カタカナ確定のショートカットとして利用可
