# EPOMAKER Split65 を NICOLA親指シフト+無線対応に鍛え上げた話(ドラフト)

## 導入
実業団でアメフトをやっていてオフェンスラインコーチもやっている現役エンジニアです。入社当初から愛用している Epomaker Split65 を、NICOLA配列(親指シフト)の実用キーボードに鍛え上げた記録です。バージョンv1からv34まで、34回のファーム迭代の物語です。

## つまずきポイントと解決(ハイライト)
1. **ANSI基板をJIS化** — 物理はUS刻印、論理はJIS(jtuエンジン)。物理キー名で会話することの大事さ
2. **Caps地獄の解決** — タップ=IMEオフ(冪等)/ホールド=機能層。エンジン内部で0x8B/0x8Aを撃たない設計(v30/v32)
3. **「コード43」の正体** — 右Shift下のスイッチは実は「右Type-CのUSBデータ線ON/OFF」。これに気づくまで右単独起動はできなかった
4. **無線モードの破綻** — 既定の役割判定(「USBが活性な方がマスター」)だと、無線では両半身スレーブになって死ぬ → 「USB無ければ左=マスター」に役割を統合(v34)
5. **ピンホール引退** — ソフトDFU(右=直挿し+スイッチON→Fn+M)でファーム書き込みが普通の作業になった

## 学び
- 「先にログ、後に推理」を徹底すると遠回りが減る
- ファームだけでは解決しない問題(IME挙動の環境差)は、IME側設定と2層で組む
- ハードの仕様は、まだコード化されていなくても「ユーザーの感覚」が一番正確だったりする
